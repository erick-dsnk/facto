# Ordinary reference coverage — 14 November 2026

The backend now accepts developed descriptive reference accounts as corroboration for ordinary facts without requiring each account to name an underlying primary record. The internal `ordinary_reference` category is distinct from original records and attributable research. It still requires the actual entity, relation, value and material scope, two qualifying evidence families, no unresolved conflict and the existing relevance, scope, stance and verdict thresholds. It cannot grant single-source registry authority or qualify the stronger health/safety, disputed or uncertain-risk route. API contracts are unchanged.

Citation selection now asks independently for supporting, refuting or materially qualifying evidence, rather than referring to an unavailable concurrent verdict answer. Provider and evaluation-observer cleanup are nonblocking so pending cancellation cannot hide an established error or stall attempt accounting.
