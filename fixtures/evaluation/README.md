# Evaluation fixtures

`cases.json` is a metadata-only manifest with IDs, categories and the split for 48 synthetic scenarios frozen on 14 November 2026: 12 personal/opinion/nonclaims, 12 public propositions, 8 mixed/ambiguous, 8 capture/correction and 8 service/lifecycle scenarios. Twelve cases were reserved as held-out before tuning. Their bodies are kept in `cases-heldout.json`; the default runner filters the manifest to `development` before opening `cases-development.json`, so held-out inputs are not loaded by the default evaluation. The split preserved all 12 held-out records unchanged: their canonical JSON SHA-256 before and after separation is `16f927c84ed3703356280f02241b4354d35ef6337288d3495ef08b7969aa37bb`.

Blind status is qualified: a prior accidental search over the legacy combined corpus may have exposed original held-out text in a tool result. It was not an intentional held-out run and the output was not used to tune policy, but exposure cannot be ruled out. Do not claim blind-held-out accuracy from the original 12-case set. The replacement set prepared in an earlier session was unavailable.

Three separate independent 10-request campaigns have been sealed and each executed once. Campaign one resolved **2/8** eligible facts correctly and definitively, with five abstentions and one clarification without factual verdict; see [its report](../../docs/blind-evaluation-2026-11-14.md). Campaign two, on freeze `7e278906bd20e4460c431eeef4b6dd93f76a0acb`, resolved **4/8** eligible facts correctly and definitively, with zero wrong definitive results, four abstentions, 9/10 semantic admission and 9/9 selected citations relevant; see [its report](../../docs/blind-evaluation-2026-11-14-02.md) and [`live/blind-second-run-summary.json`](live/blind-second-run-summary.json). Campaign three, on final freeze `3cfdfb13d8e6d37ab956e781206d892786ba441f` (scoped source SHA-256 `e6f36587593f39415f161a64a02f0946f4758b9a90b5c2c0ac40399adfb8de85`), resolved **2/8** correctly and definitively, with zero wrong definitive answers, five abstentions and one timeout/no verdict. Admission and exact public spans matched 10/10. Independent citation review verified five of six selected sources as substantive and verdict-supporting; one HTTP 200 application-error page was unverifiable. Both definitive results had at least one verified supporting source, but only one had every selected reference verified. The third report and aggregate are [here](../../docs/blind-evaluation-2026-11-14-03.md) and [`live/blind-third-run-summary.json`](live/blind-third-run-summary.json). These purposive samples are small and use different cases/freezes; do not pool or causally compare them. Case bodies, labels, queries and detailed reviews remain sealed outside the repository.

The semantic answers in `modelFixture` and exact `candidateModelFixtures` are scripted model responses, separate from the expected actions. The harness passes these through the real Jev response validator and classifier, then runs the real verdict and presentation policies. It does not compare expected fields with themselves. Changing an expected action causes the report to fail; the harness test demonstrates this.

Synthetic evidence at `example.org` and `example.net` exists only to test source gates. Those passages are not live citations or evidence for the public statements. Expected verdicts describe a response to the supplied evidence fixture, not a human fact-check label. Labels and sources must be independently reviewed before a live accuracy study.

From the repository root:

```sh
npm run evaluate
npm run --silent evaluate > fixtures/evaluation/development-results.json
```

This is a fixed-clock, no-provider-network run. E33 correction sequencing and E43 deadline behavior use injected deterministic providers through a real local Fastify HTTP server and authenticated WebSocket; their wall-clock timings include the 10-second runtime deadline where applicable. All other development cases use scripted model answers and synthetic evidence. A `not_run` case is never counted as passing. This harness does not measure provider semantics, live retrieval, audio stopping, or outbound-query leakage.

`development-results.json` records the latest explicitly executed development run. The report also consumes the shared B7 action cases at `../actions/presentation-cases.json` and reports their denominator separately.

The `npm run evaluate -- --heldout` command remains available for exploratory checks, but this set cannot support a blind-accuracy claim because prior exposure cannot be ruled out. Do not tune on it or present it as a formal blind result. The original 12 held-out bodies remain unchanged and unrun. The third independent set was executed once against the recorded final freeze; do not rerun or recreate it. The initial implementation did not intentionally execute held-out cases.

No recordings, genuine personal statements or API credentials belong in this directory. Live runs need a separate record with provider/model/policy versions, actual source inspection, capture route, timings and costs; see `docs/evaluation.md`.

## Durable provider evaluation

The `live/` directory records authenticated provider campaigns, including the first network failure and zero-coverage runs. `npm run evaluate:live -- --plan` previews the separate bounded campaign without calls. Its terminal-completion flag is not factual success. Runs 04/05 returned 2/5 definitive unique public claims; run 06 at `7e27890` completed transport but regressed to 1/5 when Opera abstained. Final run 07 on the combined freeze completed 9/9 terminal receipts and returned 2/5 correct definitive unique factual claims, three abstentions and no wrong definitive labels. Its seven unique selected citations included one inaccessible memorial page; planet sources shared an IAU definition. Run 01's unknown-usage network failure and runs 02/03's 0/5 coverage remain preserved. The third sealed campaign's wrapper encountered EEXIST only while publishing its already-saved result; separate artifact-only recovery is documented, and that campaign was not repeated. Run 07 had no such publication failure. See `docs/live-campaign-2026-11-14.md` for attempts, usage, partial costs, provenance, citation inspection and per-run denominators. Public diagnostic inputs are separate from sealed cases.
