After each completed report arrives, freeze its hash. Extract each definitive result's exact checked text, verdict, original selected evidence IDs and matching retained URL/title/excerpt. No unselected reference can replace an inaccessible or partial selected reference. Every selected occurrence remains in its case's selected-set denominator, including extra references beyond minimum corroboration.

Root may assign disjoint URL groups to existing workers. Each worker must bind its review to original selected IDs/URLs/excerpt hashes and disclose agent inspection. Deduplicate public requests per exact original URL across groups; shared URLs may have several case-specific scope assessments. Inspect the exact proposition's entity, relation, value or contrary value, time/date role, geography/population, quantities, ordinal, negation, exceptions and conditions. The source must substantively cover the whole proposition. Contradiction needs a matching-scope incompatible alternative, not missing support. Misleading needs a specific material context defect.

Inspect selected-page content directly. Record timestamp, each issued GET and redirect, status, actual final URL, content type, retained/observed bytes, truncation, body hash, decoded text hash and the exact substantive supporting/refuting page passage/hash. A URL, HTTP200, publisher prestige or search snippet is insufficient. Bot/SSO/error pages, unrelated redirects, withheld paywall bodies and passages truncated before the material scope remain unverified. Ordinary descriptive reference material can verify an ordinary factual relation without a named primary record; this does not authenticate publisher reliability or independent provenance.

Public retrieval is limited to one first attempt per exact original selected URL, up to8redirects, a15-second total per-URL deadline including redirects/reading, and3,000,000 retained body bytes. A redirect-chain cap is not itself a factual failure; its selected reference simply remains inaccessible for full-selected coverage unless the exact required content was actually inspected within the cap. No substituted URLs or retries. Public content inspection makes no paid/provider requests. Saved bodies are outside Git. The prepared Node fetch runner enforces the total deadline, tracks actually issued requests separately from proposed denied redirects and treats cleanup as nonblocking. Text/PDF extraction is offline and cannot grant verification.

Disclose source dependence separately: same publisher/domain, copying, common studies/records, explicit attribution and unknown underlying origins. Different publishers are not authenticated independent origins. Agent content verification must not be called human review or provenance authentication.
