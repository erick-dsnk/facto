# Reusable 100-input dataset assembly

The dataset is now assembled from the four prospectively authored and independently reviewed 20-fact parts plus twenty independently authored controls. The HA01 prior-OPEN duplicate was replaced with the directly grounded Chernobyl event-year claim, and GB07 with Etna/Sicily before assembly. No provider output was available during authorship, replacement, labeling, curation or ordering. Sealed/private/held-out bodies were not accessed.

`build-dataset.py` mechanically validates balances, exact public spans and style semantics; normalizes heterogeneous source receipts; selects one bounded contiguous quote of at most 75 words from each author's inspected text windows; creates useful JSON/CSV; and pins source parts, research notes, assembler and executor-budget source bytes in the plan. It makes no network or provider request. Final independent dataset review, not the quote selector, determines semantic scope acceptance.

Counts: 100 authored synthetic inputs, 80 facts balanced 40 true/40 false across eight domains of ten each (5/5), plus 20 controls (16 skips/four clarifications). Factual styles are 56 standalone, 12 mixed private/public and 12 first-person public assertions, with the conversational facts balanced 12/12. These are independent synthetic turns and one-case cold sessions, not a real multi-turn conversation corpus. Dataset input text is intentionally shareable fiction; runtime capture still omits private-capable original strings.

Order is a portable seeded hash permutation: ascending SHA-256 of `junction-coverage-100-01-2026-11-14-v1` + NUL + label, with label tie-break. The fixed seed and all 100 ordered labels are recorded before any live observation. Truth references are metadata only and never injected into actual searches. JSON/CSV and plan texts/allowlists agree exactly; all eighty quote/body/time/URL receipts remain bound to source authorship.

Offline checks passed strict executor plan validation for 100 cases, exact exported global/per-case budget equality, 100 CSV rows, all text/allowlist cross-format matches, all nine part/research hashes, dataset/CSV pins, and all eighty bounded proof-quote hashes. No provider call occurred. Root owns final immutable freeze, paid authorization and sole one-run execution; no original study is resumed or rerun.

The plan predeclares all declared/observed/definitive denominators, multiclass truth/action confusion, both factual error directions, abstentions and missing outputs, domains/styles/conversation strata, exact-span admission, cold factual latency including failures/abstentions, controls separately, partial costs/actual attempts and full-selected citation coverage. It includes descriptive Wilson 95% interval mathematics with the explicit caveat that IID/population assumptions are not established for this purposive OPEN corpus. Completed-subset low error rates or development targets do not certify readiness.
